## Übung  3.7 (SHA256 mit Shell-Tools)

```sh
# SHA256 von gothe.txt in Hex
openssl dgst -sha256 goethe.txt | openssl dgst -hex
# Output
SHA256(stdin)= e240de6326fbe55d5347e85166ac2aee09c51df84214777be2b10b6c028233ab

# Lösungsvariante 1
openssl dgst -sha256 goethe.txt | openssl dgst -hex | cut -d "=" -f 2 | cut -d " " -f 2
# Lösungsvariante 2
# Hatte Probleme mit xxd, "bash: xxd: command not found"  curl -O xxd hat auch nicht geklappt 

# Hashwert in base64 ermitteln Variante 1
openssl dgst -sha256 goethe.txt | openssl base64 -A
# Hashwert in base64 ermitteln Variante 2
openssl dgst -sha256 goethe.txt | base64
```
### Länge in base64 Darstellung 

```
openssl dgst -sha256 goethe.txt | openssl base64 -A | wc
# Output
      0       1     116
```

### Länge in binär Darstellung 

```
openssl dgst -sha256 goethe.txt | openssl dgst -binary | wc
# Output
      0       3      32
```

### Länge in hex Darstellung 

```
openssl dgst -sha256 goethe.txt | openssl dgst -hex | wc
# Output
      1       2      80
```
